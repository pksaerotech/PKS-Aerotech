TO DEPLOY TO YOUR EXISTING GITHUB PAGES SITE:
1. Open the PKS-Aerotech GitHub repository.
2. Upload index.html, style.css, script.js to the repository root, replacing old versions.
3. Upload the images/ folder and replace images/logo.png.
4. Commit changes and refresh https://pksaerotech.github.io/PKS-Aerotech/ after GitHub Pages builds.

The hero is a built-in SVG illustration, so the old agriculture video videos1/hero-video.mp4 is no longer needed.
Contact/apply buttons open an email to pksaerotech@gmail.com. No backend/form service is required.
The Careers section is an expression of interest, not a claim that a job listing is actively open.
Please verify the LinkedIn company URL in index.html before publishing; update if your actual slug differs.
